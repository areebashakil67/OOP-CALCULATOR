# OOP-CALCULATOR
A menu based calculator using C++ and OOP concept

Features:
- Addition
- Subtraction
- Multiplication
- Division
- Menu-based operation selection
- Invalid choice handling
- Division by zero handling

OOP Concepts Used::
- Class and Object:
                  Organizing the calculator program using a class and its object.
- Encapsulation:
                  Keeping data members private.
- Constructor:
                  Initializing data members.
- Member Functions:
                   Performing separate mathematical operations.
- Access Specifiers:
                   Using private and public members.

Technologies Used::
- Programming Language: C++
- IDE: Dev-C++

How to Run:
1. Download or clone this repository.
2. Open "main.cpp" in Dev-C++.
3. Compile the program.
4. Run the calculator.

Project Objective::
                  The objective of this project is to understand and practice fundamental Object-Oriented Programming 
                  concepts through a simple calculator application.
